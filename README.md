## Trained model weights and bias-corrected SIT data

The trained SIT-BCNet checkpoint used in this study and the corresponding year-round, bias-corrected sea-ice-thickness (SIT) dataset are available as GitHub Release assets:

[Download SIT-BCNet trained weights and bias-corrected SIT data](https://github.com/chenzijing709-bot/SIT-BCNet/releases)

The bias-corrected dataset is provided as daily NetCDF4 files for 2011--2023. Each file contains a 7-day moving-average SIT field sampled at a 1-day interval on the native PIOMAS grid.
